⚠ Bazı admin API'lerde role check tutarsızlığı olabilir

=== 8.4 Veri Güvenliği ===
✓ Prisma ORM (SQL injection koruması)
✓ AWS S3 (dosya depolama, sunucuda yerel kayıt yok)

⚠ API anahtarları .env'de (NEXT_PUBLIC_ prefix'li olanlar client'a açık)
⚠ TRTC/Agora SDK App ID'leri client'a açık (NEXT_PUBLIC_)
