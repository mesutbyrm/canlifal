VERİTABANINI EXPORT ETME:
  1. Prisma şemasını indir:
     https://canlifal.com/canlifal-teknik-rapor.txt (bu dosya)
     veya prisma/schema.prisma dosyasını kopyala

  2. SQL dump almak için pg_dump kullan:
     pg_dump -h <host> -U <user> -d <dbname> > canlifal_backup.sql
     (DATABASE_URL'den connection bilgilerini çıkar)

  3. Sadece şema (veri hariç):
     pg_dump --schema-only -h <host> -U <user> -d <dbname> > schema.sql

  4. Prisma migration oluştur:
     npx prisma migrate dev --name init
     (prisma/migrations/ klasörüne SQL dosyası oluşturur)

  BÖLÜM 3: DEPOLAMA (STORAGE) SİSTEMİ
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

TÜR: AWS S3 (Abacus AI tarafından yönetilen)
SDK: @aws-sdk/client-s3, @aws-sdk/s3-request-presigner

Kullanım Alanları:
  • Kullanıcı avatarları
  • Sosyal medya post görselleri
  • Kahve falı fotoğrafları
  • Yayın thumbnail'ları
  • Broadcast görselleri
  • Chat medya dosyaları
  • Blog görselleri
  • El falı fotoğrafları

Yükleme Mekanizması:
  1. Client → /api/upload/presigned (presigned URL al)
  2. Client → S3'e doğrudan upload
  3. S3 URL'si veritabanına kaydedilir

Statik Assets: public/ klasörü (65 MB)
  • Fal görselleri, ünlü fotoğrafları, ikonlar
  • Firebase config dosyaları
  • API dokümantasyonu

    • Notifications → milyonlarca kayıt

    • OneSignal bulk push → segment bazlı olmalı
    • LLM API rate limits → queue sistemi gerekli

    • PostgreSQL → Read replica + sharding
    • Redis/Memcached → Session + cache
    • Bull/BullMQ → Job queue (LLM, email, push)
    • Kubernetes → Auto-scaling
    • Elasticsearch → Arama
    • WebSocket server ayrıştır (Socket.io/Ably)
    • Agora → Enterprise plan
