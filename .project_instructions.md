## Chat System (Sohbet)
- Chat rooms with real-time messaging via SSE (Server-Sent Events)
- IRC-style permission hierarchy: `%` superadmin (strongest) > `~` founder > `&` SOP > `@` op > `+` voice
- Global admins (admin/moderator/site_manager) auto-get `superadmin` (%) role in any room
- Room owners get `founder` (~) role
- Old 'admin' DB role maps to 'sop' for backward compatibility
- Room settings API: /api/chat/rooms/[roomId]/settings (founders+ can manage)
- Midnight cleanup: /api/chat/cleanup deletes ALL messages (Turkey time 00:00 = UTC 21:00)
- Admin panel: /admin/chat-rooms has commission rate (%) and room mute toggle in edit modal
- Key files: lib/chat-permissions.ts, app/[lang]/sohbet/[roomSlug]/page.tsx (2700+ lines)
