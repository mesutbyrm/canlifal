# Fortune Telling Platform - Project Notes

## Roles System
- **Roles**: user, moderator, finans, admin, yonetici (5 roles)
- **Admin access**: All roles except 'user' can access admin panel
- **Yönetici**: Full access to everything, can assign roles
- Middleware and all API routes check `['admin','yonetici','moderator','finans'].includes(role)`

## Currency System
- **CFC (credits)**: Given on signup, referrals, ad watching. Used for fortunes.
- **Jeton (jetonBalance)**: Purchased with real money only. Used for live sessions, gifts.
- New users get: welcome CFC (from platform_settings, default 50), jeton=0
- Referral bonus: 50 CFC to both parties (from platform_settings)
- Ad reward: 10 CFC per watch (from platform_settings)

## Membership Tiers
- Order: 1. Basic, 2. Premium, 3. Gold, 4. Diamond

## Admin Settings (platform_settings table)
- welcome_credits: 50 (Hoşgeldin CFC)
- referral_bonus: 50 (Referans bonusu)
- ad_credits_per_watch: 10 (Reklam başına CFC)
- commission_rate: 50 (Canlı falcı komisyon %)
- broadcaster_commission_rate: 50 (Yayıncı hediye komisyon %)
