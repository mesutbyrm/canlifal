# Fortune Telling Platform - Project Instructions

## Overview
Turkish fortune-telling platform (canlifal.com) with mystical/cosmic theme.

## Multiplayer Games System (Step 2)
### Architecture
- **Generic model**: `GameRoom` with `gameType` field + JSON `state` - one model for all 6 new games
- **Separate SOS model**: `SosGame` at `/api/games/sos/` — untouched, separate system
- **GameShell component**: Shared wrapper at `/components/game-shell.tsx` handles menu, lobby, play, spectate, result phases, chat, polling, betting, timer
- **Game logic**: `/lib/game-logic.ts` — pure functions for all 6 games
- **API routes**: `/api/games/room/` — generic endpoints for create, join, move, chat, viewers

### 6 New Games
1. **XOX** (`/oyunlar/xox`) — Tic-tac-toe, gameType: 'xox'
2. **Sayı Tahmin** (`/oyunlar/sayi-tahmin`) — Bulls & Cows, gameType: 'sayi_tahmin'
3. **Zar Atma** (`/oyunlar/zar`) — Best of 3 dice, gameType: 'zar'
4. **Tombala** (`/oyunlar/tombala`) — Bingo, gameType: 'tombala'
5. **Tavla** (`/oyunlar/tavla`) — Simplified backgammon, gameType: 'tavla'
6. **Pişti** (`/oyunlar/pisti`) — Turkish card game, gameType: 'pisti'

### Key Patterns
- Games use `sendMove(action)` for human moves via API
- AI games use `sendAIState(fullState)` to send complete state updates
- Turn enforcement skipped for `tombala` and `zar` (both players draw/roll)
- Betting: CFC (free credits), Jeton (paid), FREE modes with 10% commission
- Currency: CFC = user.credits, Jeton = user.jetonBalance
